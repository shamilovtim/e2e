# d3e SDK readiness evidence

The frozen d3e source passed its exact affected gate: 17,894 unit tests with one existing skip, 1,323 related tests, and 76 Node smoke passes with six conditional skips. Additional source-equivalent checks passed separately: 948 whole apple-runner, 109 focused, and 53 portable Swift checks. Fresh production and unit native artifacts share the stated source fingerprint. Ten selected native tests passed with zero failures/skips; this is not a full native-suite result. Historical source/build receipts retain their preparation-time pending-live language; subsequent execution is recorded in NATIVE-TESTS.json and the case proofs.

Matched 500-control anonymous/button/shared routes delivered four intended and zero sibling inputs each. Warm-ref medians are 1528.64/1467.10/1049.55 ms versus actual 5a medians 975.66/946.14/452.54 ms. The added 552.98/520.96/597.00 ms is a measured cost of approximately 0.52-0.60 seconds. No latency-target claim is made. Live missing refused typed target_not_ready/missing/dispatched=no in 586.12 ms with zero input and native pressReadiness only. Clipped portrait/landscape geometry, distinct blocked/ready duplicates, exact same-frame ambiguity and the unchanged 750ms fade passed. Caller cancellation in the blocked duplicate is qualified, not called a product timeout.

All three actual SDK empty-input focus paths pass: guest selector with explicit accessibility valueSource, actual native private AX ref with unmarked raw contents, and guest raw-format ref with accessibility valueSource. SDK raw output format alone does not establish a runner-tree producer. The corrected value run passes nine native checks, including both reported-value stale directions after one qualified fixture clear before different-text fill. Actual captured bindings remain unchanged; no raw-or-live fallback or placeholder-equivalence identity is asserted. Equal accessibility values across empty and literal-placeholder states do not prove equal raw contents.

Two failed phone attempts are retained. The first anonymous run stopped before measured input because inherited landscape geometry violated the portrait setup; a separate actual SDK orientation command established portrait. All 17 original recordings are included byte-unchanged, including every red/setup attempt. All streams fully decoded: 3,339 video samples, zero errors. Each video has one video track, no audio track and no AVFoundation asset metadata items.
